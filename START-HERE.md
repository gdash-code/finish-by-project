## 🐛 Troubleshooting

### "node is not recognized"
➜ Node.js not installed or computer not restarted
**Fix:** Install Node.js, restart computer

### "Cannot find module"
➜ Dependencies not installed
**Fix:** Run `npm install`

### "Port 3000 already in use"
➜ Something else using that port
**Fix:** Change port in `vite.config.js` to 3001

### Changes not showing up
➜ Browser cache
**Fix:** Hard refresh `Ctrl+Shift+R` (or `Cmd+Shift+R` on Mac)

See README.md for more troubleshooting.
